DV · Visor HTML + JS + CSS locales

Selecciona explicitamente una carpeta, elige el HTML y pulsa Abrir. Los scripts clasicos y hojas CSS relativos se resuelven en memoria. No instala nada, no escribe en la carpeta y no necesita un servidor.

Solo proyectos revisados. El iframe permite scripts pero no acceso al visor, al chat, formularios, ventanas emergentes ni conexiones fetch. No es una garantia de aislamiento para codigo hostil: un bucle infinito puede bloquear la pestaña. No selecciones carpetas con secretos. No admite modulos ES, scripts async, imports dinamicos, CSS @import, srcset, navegacion entre paginas, servidores backend o carga dinamica de archivos.

Selecciona la carpeta que contiene tu HTML y JS (maximo 20 MB).

Para leer cambios externos, vuelve a seleccionar la carpeta y abre de nuevo. No hay vigilancia automatica ni conexion con OPFS. Desde DV, exporta y extrae el proyecto primero; si usas carpeta real, selecciona esa misma carpeta aqui.
