DV · Python real en el navegador

Python se ejecuta con Pyodide en un Worker, no en CMD ni PowerShell. La primera carga descarga el runtime WebAssembly de jsDelivr; necesita Internet. No instala Python en Windows ni tiene acceso al disco de DV o a tu carpeta real.

Ejecuta solo codigo que hayas revisado. Esto no es un sandbox de seguridad para codigo hostil: Python puede usar las APIs de red del navegador. No cargues secretos. No se envia el programa a un servicio de ejecucion.

Listo. El runtime se descargara al ejecutar.

Salida y errores



Cada ejecucion empieza con un Worker y sistema de archivos virtual nuevos.
Los archivos creados por Python son temporales y se pierden al terminar.
No admite programas de escritorio, procesos nativos, C, ni acceso directo a OPFS.
La carga tiene un limite separado de 120 segundos; Detener funciona tambien
durante la descarga. Si tu navegador bloquea Workers desde archivos locales,
abre esta pagina mediante un servidor local existente.
